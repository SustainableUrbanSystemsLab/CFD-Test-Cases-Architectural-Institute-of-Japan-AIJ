# API

A **static** API: every endpoint is a file under `/api/` on this site, generated by `scripts/build_api.py` from the
cleaned data and served by GitHub Pages. Plain HTTP GET, no keys, no rate limits beyond GitHub's, CORS-open.

- Base URL: `https://sustainableurbansystems.com/CFD-Test-Cases-Architectural-Institute-of-Japan-AIJ/api`
- Fallback (the same files, raw from the repository): `https://raw.githubusercontent.com/SustainableUrbanSystemsLab/CFD-Test-Cases-Architectural-Institute-of-Japan-AIJ/main/docs/api`
- Machine description: [`/api/openapi.json`]({{ '/api/openapi.json' | relative_url }}) (OpenAPI 3.1) · agent entry point: [`/api/llms.txt`]({{ '/api/llms.txt' | relative_url }})

Every JSON file carries `schema_version`, `generated_from` (the git commit of the data it was built from),
`generated_at` and `licence`.

## Endpoints

| Endpoint | What it returns |
|---|---|
| [`GET /api/index.json`]({{ '/api/index.json' | relative_url }}) | every endpoint, versions, licence, how to cite, the agent walk |
| [`GET /api/cases.json`]({{ '/api/cases.json' | relative_url }}) | the five cases: id, title, configuration facts, units, frame, counts, which engines are validated, links |
| `GET /api/cases/{id}.json` | one case in full: configurations (Case C's 9, Case E's pre/post), inflow fit and the measured approach-flow profile, reference-point summary, geometry files, validation status, gotchas, attribution |
| `GET /api/cases/{id}/points.json` | the cleaned measurement table: SI units, one frame per case, `null` for unmeasured; `columns` and `column_meaning` say what each field is |
| `GET /api/cases/{id}/points.csv` | the same table as CSV (empty cell = null) |
| `GET /api/cases/{id}/geometry.json` | frame, configurations, the **box list** where the geometry is boxes (A, B, C, D), per-file STL statistics (triangles, bbox, volume, edge-manifold census) |
| `GET /api/cases/{id}/geometry.stl` | cleaned ASCII STL of the default configuration, metres, outward normals, origin at the building / array centre |
| `GET /api/cases/{id}/geometry_{configuration}.stl` | the other configurations: `C/geometry_0D.stl`, `C/geometry_1D.stl` (`geometry.stl` is 2D), `E/geometry_bc.stl` (`geometry.stl` is after construction) |
| `GET /api/cases/{id}/validation.json` | Eddy3D scores per engine with the figure URLs; `results` is an **empty list** where no validation has been run |
| [`GET /api/openapi.json`]({{ '/api/openapi.json' | relative_url }}) | OpenAPI 3.1 description of the above |
| [`GET /api/llms.txt`]({{ '/api/llms.txt' | relative_url }}) | plain-text entry point for agents |

`{id}` is one of `A`, `B`, `C`, `D`, `E`.

## What each case serves today

| Case | points | geometry | validation |
|---|---|---|---|
| A | 186 rows: U, V, W, uu, vv, ww, k (variances; metres) | 1 box, 12 triangles, generated from the stated 0.08 × 0.08 × 0.16 m | OpenFOAM 12 realizable k-ε: R, FAC2, FB, hit rate, NMSE, NAD, MG, VG per quantity |
| B | 224 rows: U, V, W, uu, vv, ww, k (mm → m; V sign flipped to +y) | 1 box, 12 triangles, 0.05 × 0.20 × 0.20 m | OpenFOAM 12 realizable k-ε, as A |
| C | 1080 rows: Vs over 9 configurations (`config` 0D/1D/2D × `wind_direction_deg` 0/22.5/45) | 3 STLs (0D: 8 cubes, 1D/2D: 9 boxes) + box lists | none yet (`results: []`) |
| D | 267 rows: 234 thermistor (78 points × 3 directions, 36 unmeasured) + 33 split-fibre with U, V, W, uu, vv, ww, k; mm → m | 83 boxes, 996 triangles, watertight, rebuilt from the dirty shipped STL | none yet |
| E | 2560 rows: velocity ratio over `config` bc/ac × 16 compass directions × 80 points; full-scale metres | 2 STLs from the 3dm (bc 8400, ac 8436 triangles), outward-oriented; not watertight (touching buildings share 15 edges) | none yet |

## Examples

### curl

```bash
BASE=https://sustainableurbansystems.com/CFD-Test-Cases-Architectural-Institute-of-Japan-AIJ/api

curl -s $BASE/index.json | jq '.endpoints[].path'
curl -s $BASE/cases.json | jq '.cases[] | {id, title, counts, engines}'
curl -s $BASE/cases/B.json | jq '{frame, units, inflow_fit}'
curl -s $BASE/cases/B/points.json | jq '.points[:3]'
curl -s -o caseB.csv $BASE/cases/B/points.csv
curl -s -o caseD.stl $BASE/cases/D/geometry.stl
curl -s $BASE/cases/D/geometry.json | jq '.files[0].boxes | length'      # 83
curl -s $BASE/cases/A/validation.json | jq '.results[0].scores["velocity.U"] | {R, Fac2, Fb, HitRate}'
curl -s $BASE/cases/C/validation.json | jq '.results'                     # [] — not validated yet
```

### Python

```python
import io, csv, json, urllib.request

BASE = "https://sustainableurbansystems.com/CFD-Test-Cases-Architectural-Institute-of-Japan-AIJ/api"

def get(path):
    with urllib.request.urlopen(f"{BASE}/{path}") as r:
        return r.read()

index = json.loads(get("index.json"))
cases = json.loads(get("cases.json"))["cases"]

case = json.loads(get("cases/B.json"))
print(case["frame"]["x"], case["units"])            # read the frame BEFORE the numbers

pts = json.loads(get("cases/B/points.json"))
U_H = case["configuration"]["U_H_m_s"]
centre = [p for p in pts["points"] if abs(p["y"]) < 1e-9 and p["U"] is not None]
print(len(centre), "centre-plane points; U/U_H at the first:", centre[0]["U"] / U_H)

# CSV, if you prefer a DataFrame
rows = list(csv.DictReader(io.StringIO(get("cases/C/points.csv").decode())))
print(rows[0])                                      # {'point_id': '63', 'config': '0D', ... 'Vs': '2.75'}

# geometry: boxes where it is boxes, STL otherwise
geom = json.loads(get("cases/D/geometry.json"))
boxes = geom["files"][0]["boxes"]                   # 83 x {min:[x,y,z], max:[x,y,z]} in metres
open("caseE_after.stl", "wb").write(get("cases/E/geometry.stl"))

# validation: an empty list means no validation exists for that case
val = json.loads(get("cases/A/validation.json"))
for r in val["results"]:
    print(r["engine"], {q: round(s["R"], 3) for q, s in r["scores"].items()})
```

### Geometry conventions

- Metres. Model scale for A–D (the scale the tunnel measured at); full scale for E (the scale its 3dm and workbook
  are in). `geometry.json` → `units` states it.
- Origin at the building (A, B) / array (C, D) centre on the ground plane; for E, the centre of the reproduced area.
- +x along the wind at WD = 0 for A–D. E keeps its geographic frame (+x east, +y north); its directions are
  meteorological (the direction the wind comes **from**, N = 0°, clockwise).
- Outward normals, LF line endings, one `solid` per file. A–D are watertight; E's shells touch and are not.
- Every STL is checked at build time: triangle count, edge-manifold census, bounding box against the stated
  dimensions, and one render (`validation/geometry/stl_check_caseD.png`).

## Regenerating

```bash
pip install xlrd rhino3dm matplotlib
python scripts/build_api.py          # builds docs/api/ and docs/cases/, then verifies
python scripts/build_api.py --check  # verify only
```

The point tables come from `clean/` when `clean/manifest.json` names them (the canonical cleaned release) and from
the raw case folders otherwise; `points_source` in each `points.json` says which. Validation scores are read from
`validation/results/*.json`, snapshots of the Eddy3D fixtures' `results.json`.
